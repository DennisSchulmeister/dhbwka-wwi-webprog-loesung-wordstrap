# Webprogrammierung / Lösung / Wordstrap

Dies ist die **Musterlösung** zur Aufgabe „Wordstrap" aus der Vorlesung **Webprogrammierung** (Wirtschaftsinformatik, DHBW Karlsruhe), Kategorie *Responsive Webdesign*.

Eine an Microsoft Word/Google Docs angelehnte Programmoberfläche namens „Wordstrap“ wird komplett mit Bootstrap-Komponenten nachgebaut (noch ohne JavaScript-Logik).

Dieses Repository ist Teil der Quellcodes [dhbwka-wwi-webprog-quellcodes](https://github.com/DennisSchulmeister/dhbwka-wwi-webprog-quellcodes) zur Vorlesung Webprogrammierung.
